# Project instructions

## Project overview
- This is a small Angular application for a calculator.
- The root app is in `src/app/`; the calculator component is in `src/component/`.
- Keep component logic in TypeScript files and markup in their corresponding HTML templates.

## Working in this repository
- Use npm and the existing Angular CLI setup.
- Follow the patterns and formatting of nearby files.
- Keep changes focused; avoid adding dependencies unless the task needs them.
- Preserve the existing TypeScript and Angular compiler settings.

## Verification
- Run `npm run build` after application changes.
- Run `npm test` when changing behavior, and add or update focused tests for that behavior.

## Calculator behavior
- Follow the arithmetic and UI behavior requested for the task.
