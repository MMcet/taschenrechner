# Taschenrechner

Overengineered Taschenrechner for presentation.

This repository contains a basic Angular application generated with Angular CLI.

## Development

Install dependencies and start the development server:

```bash
npm install
npm start
```

Open `http://localhost:4200/`. The app reloads automatically when source files change.

## Build and tests

```bash
npm run build
npm test
```

Generate Angular components and other project files with:

```bash
npx ng generate component component-name
```
